# 共有コンテキスト（shared-context）

このリポジトリは、太陽さんが使う複数のAI（迅、ChatGPT／Codex、Claude Code）が、**同じ前提・同じ学習内容で動くための単一の情報源（Single Source of Truth）** です。

やってきたこと、決めたこと、文面の癖、事業の引き継ぎ事項は、ここに集約します。各AIは作業前にここを読み、終わったら決定事項をここへ戻すことで、AIごとに文脈がずれるのを防ぎます。

## 構成

| パス | 内容 |
| --- | --- |
| `knowledge/user-profile.md` | 太陽さんの本業、副業、関心、投資方針、作業姿勢 |
| `knowledge/writing-style.md` | 文面の癖、添削ルール、営業文・集客文の型、成果物のまとめ方 |
| `knowledge/hp-business-handover.md` | ホームページ事業の価格、C案、候補3社、営業ルール、未確定事項 |
| `knowledge/instagram-business.md` | Instagram の目標、アカウント割り当て、承認フロー、自動投稿スペース |
| `knowledge/ai-staff-roles.md` | 迅、Codex、Claude Code、AI社員5人の役割分担 |
| `decision-log.md` | 日付付きの決定事項ログ（時系列） |
| `AGENTS.md` | Codex がこのリポジトリで作業するときの入口 |
| `CLAUDE.md` | Claude Code がこのリポジトリで作業するときの入口 |
| `chatgpt-summary.md` | ChatGPT のカスタム指示・プロジェクトに貼るための凝縮版 |

## 各AIの読み方

### 迅（Muse）

- 原典は `~/MEMORY.md` と各プロジェクト資料。ここはその共有用ミラー。
- 作業開始時に、関連する `knowledge/` ファイルだけを読む。

### Codex

- このリポジトリ（またはフォルダ）を開いたら、まず `AGENTS.md` を読み、指示に従って `knowledge/` の該当ファイルを参照する。
- ホームページ事業のプロジェクト内では、プロジェクト側の `AGENTS.md` と仕様書が優先。

### Claude Code

- このリポジトリで作業するときは、まず `CLAUDE.md` を読み、指示に従って `knowledge/` の該当ファイルを参照する。
- 常時ルールは `~/.claude/CLAUDE.md`、詳細パックは `~/workspace/claude-context/` にもある。

### ChatGPT

- ファイルを直接は読めないため、`chatgpt-summary.md` の内容をカスタム指示またはプロジェクト指示に貼って使う。
- 事業の詳細が必要な場面では、太陽さんが該当の `knowledge/` ファイルをチャットに添付する。

## 更新ルール

1. **決定事項が変わったら、迅がここを更新する。** 古い決定を別ファイルに散らさず、該当する `knowledge/` ファイルへ日付付きで反映し、無効になった旧決定はその旨を明記する。
2. **すべての決定は `decision-log.md` に追記する。** 日付、決定内容、根拠資料への参照を1件ずつ残す。過去の行は書き換えない（訂正は新しい行で「○年○月○日の決定を訂正」と明記する）。
3. 資料同士が矛盾する場合は、古い方を自動で上書きせず、矛盾点と日付を示して太陽さんに確認する。
4. 資料にない事実は推測で補わない。推測が必要な場合は「仮説」と明記する。
5. 認証情報、パスワード、業務に関係のない私的な詳細は、このリポジトリに入れない。
6. 価格、投稿先アカウント、承認ルールなど実行結果に直接影響する項目は、作業前に必ず最新の原典（プロジェクト資料）でも確認する。

## 優先順位の目安

1. 太陽さんの最新の明示的な指示
2. 対象プロジェクトの `AGENTS.md`、仕様書、最新の決定資料
3. このリポジトリの `knowledge/` と `decision-log.md`
4. 古い下書き、過去の提案、一般論

## GitHub について

このフォルダは git リポジトリとして初期化済みです。GitHub のプライベートリポジトリ `shared-context` へ push すれば、Codex（クラウド）や他のマシンからも同じ内容を clone して使えます。push の状態は、このファイルではなく運用メモ（迅の報告）で管理します。
